# YottaBot's Homebrew tap

```bash
brew install yottabot-platform/tap/yottactl
```

[yottactl](https://github.com/YottaBot-Platform/yottactl) is YottaBot's
command-line tool, for macOS and Linux. `brew upgrade yottactl` updates it.
The formula installs the same signed builds as
[yotta.bot/platform/install](https://yotta.bot/platform/install), and each
yottactl release updates it here.

Bugs and requests: open an issue in
[YottaBot-Platform/yottactl](https://github.com/YottaBot-Platform/yottactl/issues).
